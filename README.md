# Interstellar-Flight

航空主题桌面专注应用。将每次专注化为一场星际航班，在苍穹界中穿梭 58 座城市，积累里程，解锁成就。

## 技术栈

**Electron 42** + **React 19** + **TypeScript** + **Three.js** / **React Three Fiber** + **Zustand** + **Tailwind CSS** + **Vite**

## 功能

### 3D 星际地图
- 7 大星系团、58 颗恒星城市
- 400 条航线光束，自由旋转/缩放/平移
- 双城市选择预订系统：第一颗出发（金色）、第二颗到达（蓝色）

### 舷窗视角
- 程序化星空（四层 9000+ 星点）
- 8 颗 Canvas 程序化行星（类地/气态/岩质/冰封 + 大气背光 + 行星环）
- 银河带、粒子彗星、流星、星云球
- 航线光束 + 金色飞机沿航线移动
- 实时倒计时面板 + 进度条

### 机舱选座
- 全机舱 30 排 200+ 座位
- 4 个舱段（FIRST / BUSINESS / ECONOMY 前段 / ECONOMY 后段）
- 靠窗/过道/中间座位颜色区分
- 全部座位可自由选择

### 悬浮窗
- 5 套主题可切换（暗星云 / 金辉航线 / 霜境 / 余烬 / 苍翠）
- 半透明毛玻璃 UI
- 大机票风格：城市代码 + 中文名 + 航班号 + 倒计时 + 进度条
- 进度条随动小飞机 ✈
- WAV 合成结束音效（C6→E6→G6→C7 上行琶音）
- 航班结束时自动恢复主窗口 + 弹出结算面板

### 评级系统
- ⭐ 0-25 分钟 · ⭐⭐ 25-60 分钟 · ⭐⭐⭐ 60-120 分钟 · 👑 120 分钟以上
- 评级显示在登机牌、结算面板、悬浮窗

### 数据持久化
- JSON 文件存储航班历史
- 统计数据（总里程、总时长、连击数）跨会话保留

## 开发

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建
pnpm build

# 打包（解包版）
npx electron-builder --win dir
```
